モドリカ

モドリカ（NEXT ENGINE 向けの返品・交換アプリ）がアクセス・保存・送信する情報と、その削除について。

2026年10月18日施行 · 公開者名：7thcode

このページの内容

適用範囲アクセスする情報保存する情報利用目的提供者と保管場所AI の分析外国にある事業者外部送信保持と削除権利と請求変更

1. 適用範囲と提供者

本通知は、NEXT ENGINE のアプリ「モドリカ – 返品・交換セルフ管理」（以下「モドリカ」）と、その購入者向けの申請画面に適用されます。モドリカは 7thcode（屋号）が提供します。本通知は 7thcode プライバシーポリシーを補足し、モドリカに固有の記載が優先します。

モドリカには 2 種類の利用者がいます。NEXT ENGINE を契約し、モドリカで返品・交換を受け付ける「ショップ」（その担当者を含む）と、ショップから商品を購入し、返品・交換を申請する「購入者」です。購入者の情報はショップの顧客情報であり、その利用目的はショップが定めます。モドリカはショップの委託を受けて購入者の情報を処理します。

2. モドリカがアクセスする情報

ショップ。NEXT ENGINE からモドリカを起動したときに、企業の識別子と企業名、起動した担当者の識別子と氏名を受け取ります。ショップが NEXT ENGINE で許可した範囲で、店舗の一覧、受注（注文番号、明細、日付、出荷の状況、購入者の氏名・住所・電話番号・メールアドレス）、商品と在庫、在庫の入出庫履歴（在庫を戻したことの確認）、受注一括登録パターン、支払方法・発送方法の設定、登録した伝票の取り込み処理の状況、企業の住所と連絡先を読みます。

購入者の電話番号と郵便番号は、申請画面での本人確認の照合にだけ使い、保存しません。購入者と送り先の氏名・住所・電話番号・メールアドレスは、ショップが交換伝票の自動作成を設定して交換を承認したときに、交換品の受注伝票を NEXT ENGINE に作るために元の受注から読み、そのまま NEXT ENGINE に送ります。モドリカには保存しません。

購入者。申請画面で入力した内容（注文番号、本人確認のための電話番号または郵便番号、返品か交換か、商品と数量、理由、商品の状態、状況の説明、ショップへのメモ）、任意で入力したメールアドレス、任意で添付した写真を受け取ります。写真は購入者の端末で縮小され、サーバーでも撮影位置などの付加情報（EXIF など）を取り除いてから保存します。

アクセス記録。総当たりによる不正な照合を防ぐため、本人確認の試行を、注文と結び付けたハッシュ値で記録します。ホスティング事業者は、通常の運用のため、IP アドレスやアクセス日時を含む通信記録を処理する場合があります。

3. モドリカが保存する情報

  • 企業と店舗: 企業の識別子と企業名、店舗名、返送先、問い合わせ先のメールアドレス、各種設定、NEXT ENGINE のアクセストークン（暗号化して保存）と接続した担当者の識別子
  • ルール: 返品・交換のルールとその版、保存した担当者
  • 申請: 受付番号、注文番号、注文の明細と日付の写し（購入者の連絡先は含みません）、理由、商品の状態、状況の説明、メモ、購入者のメールアドレス（入力した場合）、写真、検品の結果とメモ、返金額と返金の記録、返送と交換品の追跡番号、交換伝票の番号、状況確認ページの鍵（照合用のハッシュ値と、メールに載せるための暗号化した値）
  • 履歴と処理: 申請の履歴（操作した担当者を含む）、NEXT ENGINE への登録処理の記録、送信したメール（宛先、件名、本文）、AI の分析の記録（送信した文章と結果。後述）
  • その他: ショップが発行した個別リンク（ハッシュ値）、本人確認の試行記録（ハッシュ値）、月ごとの申請件数と NEXT ENGINE の API 呼び出し回数

4. 利用目的

要求された機能の提供（申請の受付、ルールによる判定、購入者とショップへのメール、NEXT ENGINE での交換伝票の作成と在庫の更新、分析と CSV の出力）、ショップが有効にした場合の AI の分析、不正利用の防止、料金の計算のための件数の計測、障害の調査、法令上の義務への対応のためにのみ利用します。購入者の情報を販売したり、データブローカーに開示したり、ターゲティング広告に使ったりすることはありません。

5. 提供者と保管場所

モドリカは Railway Corporation（アメリカ合衆国）のクラウドで動作し、データ（写真を含む）はシンガポールにあるサーバーのデータベースに保管されます。

次の事業者が、サービス提供に必要な範囲で限定的な情報を処理します。

  • NE株式会社 — NEXT ENGINE（受注・商品・在庫の読み取り、交換伝票と在庫の登録、アプリの利用料金の請求）
  • Resend — 購入者とショップへのメール送信（宛先のメールアドレス、件名、本文）
  • OpenAI — AI の分析（ショップが有効にした場合のみ。後述）
  • Railway Corporation — アプリとデータベースの運用（サーバーはシンガポール）
  • Cloudflare, Inc. — DNS

これらの事業者は、自らの条件および適用法令で認められた地域でデータを処理する場合があります。

6. AI の分析

AI の分析は、ショップが店舗ごとに有効にする機能で、最初は無効です。有効にした店舗では、申請・購入者の回答・写真の追加のたびに、申請の内容を OpenAI の API に送り、担当者向けの参考情報（おすすめの対応、確かめるべき点など）を受け取ります。承認や却下を決めるのは担当者で、AI が購入者に連絡することはありません。

  • 送る情報: 返品・交換の種類、商品名・数量・単価、交換先の商品名、理由、商品の状態、状況の説明、ショップへのメモ、ショップと購入者のやりとり、ショップのルールの要点とルールでの判定、注文・出荷・申請からの経過日数、写真（新しいものから最大 4 枚）
  • 送らない情報: 注文番号、受付番号、購入者のメールアドレス。文章中の電話番号・メールアドレス・郵便番号・10 桁以上の番号は、送る前に取り除きます。ただし、文章中に書かれた氏名や、写真に写り込んだ情報は残る場合があります
  • 記録: 送った文章（上記の取り除きをしたもの）と結果を、申請ごとに保存します
  • OpenAI での取り扱い: OpenAI の公開情報によれば、API に送られたデータは OpenAI のモデルの学習に使われず、不正利用の監視のため最長 30 日保持されます。詳しくは OpenAI の各ポリシーをご覧ください

7. 外国にある事業者への提供

Railway（アプリとデータベースの運用）、OpenAI（AI の分析）、Resend（メール送信）はアメリカ合衆国の事業者です。データベースはシンガポールにあるサーバーに保管されます。これらの事業者には、サービス提供に必要な範囲で情報の取り扱いを委託しています。アメリカ合衆国とシンガポールの個人情報の保護に関する制度は、個人情報保護委員会が公表している外国の制度の情報をご覧ください。各事業者が講じている措置は、それぞれのポリシーで公表されています。

8. 外部送信

モドリカの購入者向け申請画面、ショップ向け管理画面、紹介ページでは、利用者の端末から第三者へ情報を送るタグ（アクセス解析や広告など）を使用していません。書体と画像もモドリカのサーバーから配信しています。

9. 保持と削除

申請に使われなかった写真は、アップロードから 24 時間で自動的に削除されます。申請、写真、履歴、送信したメール、AI の分析の記録は、ショップがモドリカの利用を続ける間保持します。ショップが NEXT ENGINE でモドリカの利用を終了したときは、終了した日から 1 か月後に、そのショップのデータ（写真、AI の分析の記録、送信したメールを含みます）を削除します。バックアップに残るコピーは、ホスティング事業者の保持期間に従って消えます。

10. 権利と請求

お住まいの地域によっては、個人情報の開示、訂正、削除、利用停止などを求める権利があります。購入者の方は、申請の内容を受け付けているのは購入したショップであるため、まずショップの問い合わせ先へご連絡ください。ショップの方、およびモドリカ自体の処理に関するご請求は、対象の受付番号を添えて以下からお送りください（日本の営業日 10:00〜17:00 に確認します）。最初の連絡に認証情報や写真を含めないでください。
